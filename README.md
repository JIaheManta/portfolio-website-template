# Portfolio Website Template

A reusable static portfolio template with responsive layouts, animated project cards, project detail pages, a gallery and an About page.

This repository contains only generic placeholder content. It does not include the original creator's personal projects, photographs, videos or biography.

## Use

1. Edit `dist/app.js` to replace the placeholder name, introduction and project text.
2. Replace the CSS placeholder blocks with your own images if needed.
3. Open `dist/index.html` locally or deploy the `dist` directory to any static hosting service.

## Structure

- `dist/index.html` — page entry
- `dist/app.js` — content, routing and interactions
- `dist/*.css` — layout, motion and responsive styling
