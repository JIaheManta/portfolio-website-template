# Art & Design Portfolio Website Template

A reusable, responsive portfolio website template created for art and design students, independent artists and multidisciplinary creatives.

It is suitable for:

- Visual and graphic design
- Illustration, painting and fine art
- Moving image, animation and photography
- AIGC, digital media and creative technology
- Multidisciplinary and experimental practices

## Features

- Responsive layouts for desktop and mobile
- Animated horizontal project cards
- Scroll-guided 16:9 project showcase
- Individual project detail pages
- Gallery and About sections
- Bilingual content support
- CSS visual placeholders that are easy to replace

## Privacy

This public repository contains only generic placeholder content and website code. It does **not** include the original creator's personal project images, photographs, videos, biography, contact details or private source materials.

## Use

1. Edit `dist/app.js` to replace the placeholder name, introduction and project text.
2. Replace the CSS placeholder blocks with your own artwork or project images.
3. Open `dist/index.html` locally or deploy the `dist` directory to any static hosting service.

## Structure

- `dist/index.html` — page entry
- `dist/app.js` — content, routing and interactions
- `dist/template.css` — layout, motion and responsive styling
